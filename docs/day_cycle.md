# Цикл дня и закупки

Игра начинается с дня 1. Кнопка «Закрыть магазин» открывает ночной экран
поставщика. В нём пять фиксированных предложений по одному экземпляру;
купить каждое можно один раз за ночь. На следующую ночь ассортимент доступен
снова с новыми экземплярами тех же карт.

«Начать следующий день» доставляет оплаченные экземпляры в существующий
альбом `SecondCardBinder`, первоначально находящийся в подстольном хранилище.
Если альбом перемещён на стол, доставка попадает в него же. При заполнении
альбом расширяется по шесть мест; доступны обычные страницы и извлечение карт.

## Владение состоянием

- `GameState.day_cycle` — `DayCycleManager`: номер дня, фаза, предложения,
  отметки покупок и ожидающие заказы. День увеличивается только ночью → утром.
- Денежные операции используют существующий `GameState` / `ShopWallet`.
- Заказ содержит существующий `Card`, созданный при открытии ночных предложений.
  Утром в `CardCollection` передаётся тот же объект с тем же `specimen_id`
  и характеристиками, без повторной генерации.
- `day_cycle_screen.gd` сохраняет загруженную сцену магазина, скрывая её и
  отключая обработку на ночь. Карты на поверхностях, альбомы, текущая сделка
  и незавершённая передача сохраняются. Покупатель и таймеры продолжаются утром.
- `night_supply.gd` отображает предложения, баланс и оплаченные заказы.

Сохранение здесь действует между фазами текущего запуска игры; сохранение
на диск и восстановление после выхода не добавлялись.

## Проверка

Запустить Godot с `--headless --path . res://verification/day_cycle_smoke.tscn --quit-after 400`.
Успех отмечен строкой `DAY_CYCLE_SMOKE_OK`. Проверяются исходная фаза,
недостаток средств, точное списание, повторная покупка, неверный индекс,
отложенная доставка, идентичность экземпляров, сохранность прежних карт,
рост альбома, извлечение доставленной карты и повторные переходы.
При запуске теста с графикой снимок ночного экрана сохраняется в
`user://night_supply_preview.png`.
