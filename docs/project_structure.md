# Структура проекта

Проект содержит один актуальный игровой контур: PP-like экран магазина с двумя drag-and-drop пространствами — столом и прилавком.

- `assets/` — весь визуальный контент: изображения карт, портреты, шрифты и UI-графика;
- `data/` — контентные JSON. Сейчас игра загружает каталог `cards.json` и карточные подписи из `text.json`; остальные JSON сохранены как контент для будущих механик;
- `scenes/screens/shop_table_screen.tscn` — текущая точка входа;
- `scenes/gameplay/` — верхняя магазинная область, рабочая зона и журнал карт;
- `scenes/ui/card_view.tscn` — полное представление карты;
- `scenes/ui/draggable_card.tscn` — единый объект карты с представлениями для стола и прилавка;
- `scenes/ui/drag_drop/` — переиспользуемый drag-and-drop компонент;
- `scripts/core/` — загрузчик контента, каталог карт и пути к карточным ресурсам;
- `scripts/domain/card.gd` — модель карты;
- `scripts/gameplay/card_binder.gd` — страницы, слоты и содержимое журнала;
- `scripts/ui/` — представления карт и общая drag-and-drop логика.

## Журнал карт

`scenes/gameplay/card_binder.tscn` — самостоятельный draggable-объект с двумя представлениями. На столе он показывает открытую страницу, на прилавке — компактную закрытую обложку.

- `page_count` в инспекторе задаёт количество страниц; по умолчанию их 3;
- на каждой странице всегда 6 ячеек;
- `initial_card_ids` задаёт стартовое содержимое через ID из `data/cards.json`;
- `get_stored_cards()` возвращает список лежащих в журнале карт;
- захват карты из занятой ячейки создаёт обычную `DraggableCard` на столе;
- отпускание такой карты над пустой ячейкой возвращает её данные в журнал.

## Куда добавлять новое

- Новая карта: запись в `data/cards.json` и изображение в `assets/cards/`.
- Новый текст карточного UI: секция `ui` в `data/text.json`.
- Новое представление предмета: сцена в `scenes/ui/`, основанная на общем draggable-компоненте.
- Новое правило стола или прилавка: `scripts/ui/drag_drop/ui_drag_surface.gd` либо отдельный gameplay-компонент, если правило не является общим для drag-and-drop.
- Новый игровой экран: `scenes/screens/`, без смешивания доменной логики с разметкой интерфейса.

Старые экраны диалогов, туториала, списка торговцев и прежнего trade UI удалены. Контентные изображения, карты и JSON при этом сохранены.
